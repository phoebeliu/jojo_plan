# jojo plan · 替身计划：产品研究工作区

更新日期：2026-09-25。当前阶段：产品研究与定义。

本轮产物是文献调研与产品讨论稿。没有完成用户研究、候选框架实测或产品评审，不将其标记为“调研完成”或开发基线。

1. [产品与技术调研](research.md)：一手资料、候选方案、证据边界和待验证项。
2. [产品方案](product-proposal.md)：定位、三类工作、开发协作流程和产品机制。
