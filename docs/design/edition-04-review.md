# Design Edition04：个人交付替身与可解释情境界面

2026-10-09｜S2定位。基于Edition03交付闭环增加Personal AI与Intelligent UI，不新增全局tab。

## 可操作的设计变化

- 工作标题区「按你的方式」入口：查看准则、来源和作用域；可以暂停本次使用，恢复时保留原数据。
- 个人方法与项目约束分别呈现：系统研发方法可复用，审计规则不会带入护照项目。
- 经验候选：加入验证清单或忽略；接受后明确待验证、尚未启用。
- 当前检查点按范围、方法、来源、依据或变更选择表现：需求变化后转向变更复核。
- 点推荐标签查看原因：当前任务、当前状态、个人准则和不确定性；可固定检查点或恢复自动推荐。
- 固定组件仍更新版本和失效状态；关闭个人化仍保留任务的验收、权限与风险。
- 新工作和设置文案改为个人交付替身；PPT继续保留能力缺口与不可运行提示。

## 实际自检

先核查官方实践，再在已有品牌/对话骨架上设计。实际截图审查发现解释入口与个人来源信息会挤占当前检查点，因此将来源细节收入同一详情区，维持首屏协作、成果和下一步的可读性。新增面板覆盖1440/1100/768/390四种宽度及键盘操作；候选与个性化开关采用工作级演示状态。

当前实现是确定性内存状态与受控HTML组件，不调用模型产生ViewIntent，不执行真正长期学习/遗忘/导出。屏幕中的已明示方法来自本对话里的用户要求；经验候选为合成复盘示例。来源、scope及验收边界详见[S2规格](../spec/17-personal-ai-intelligent-ui.md)。

## 研究和竞争边界

最新来源、个人AI/智能UI概念区分及护城河机制见[S2研究](../strategy/07-personal-ai-intelligent-ui.md)。用户可管理记忆和按任务生成界面已存在强竞争；本版不把这些能力当作独家发明。选择可信组件目录与固定审批语义是本产品设计判断，不声称所有生成UI都必须采用同一路径或已接入A2UI。

## 下一步真实实现需验证

个人准则的准确性、作用域与遗忘；模型提案的权限/版本检查；编辑时布局稳定性；建议带来的实际工时与质量收益。客户资料不自动进入公共经验。用户资产可完整迁移，留存应来自方法与工作连续性，不来自封闭存储。

本轮品质目标继续沿用Edition03的可读性、结构、交互与原创表达。没有独立奖项评审或真实用户成绩，不以自检作为“不可替代”的证明。
