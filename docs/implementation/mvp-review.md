# 0.2.0 MVP 验收报告

2026-10-10。本轮从 0.1.0 文本切片推进到可本机试用的三路径 MVP。验收标准是**保存材料和方法 → 真实生成 → 版本化检查/审阅 → 可用格式交接 → 修改/重启后仍正确**；系统还要求阶段门槛与真实容器测试。不是完整 JP-1.1 或客户生产系统最终验收。

## 本轮验收

| 检查 | 证据与实际结果 |
|---|---|
| 类型/领域/协议 | strict TypeScript；23 条领域及两协议合成 SSE 集成测试通过。协议 fixture 证明 SDK 请求/流/用量解析，不冒充供应商真实模型调用 |
| 七阶段真实模型系统 | 22 项闭环检查通过。实际合成待办 API：健康检查、创建/查询、错误标题、JSON 错误、页面、独立内存实例等；6 条 Node 测试通过，源码导出后独立复测也通过 |
| 失败不冒充通过 | 人为失败用例实际返回失败；机器门槛拒绝。早期 Mac 挂载挂起留下四次失败历史，没有改写成成功；固定镜像构建 runner 修复后恢复已批准前序阶段继续 |
| 终审/交付 | 各阶段独立调用和成果；前五个批准与研发批准均不提前交付。终审包含实际前序检查日志，最终使用合成测试 actor 批准；不是人工客户验收 |
| Skill | 真实模型生成满足 frontmatter/输入/步骤/输出/例/边界；导出标准 skills/api-requirement-check/SKILL.md；未批准 Skill 不能被选用，跨项目不能选用 |
| 文档 | 4 项真实模型检查通过：用实际合成容器日志＋显式选用 Skill 生成报告，包含准确来源版本、合成与生产局限；审阅后 document.md 与批准版本一致 |
| 公共来源 | 3 项实际检查通过：读取 IANA 公共正文、保存独立材料/来源 URL/真实 Job 完成；环回地址被拒绝且未增加材料 |
| 容器隔离 | 3 条实际测试通过：uid=1000、无宿主挂载/Socket；工作区写入被拒绝；外网连接被拒绝。基础镜像锁定摘要，固定构建步骤，不运行模型安装脚本 |
| 原生交互 | 新 MVP 6 项与旧数据/原生回归 6 项通过：原生新建七阶段工作、真实文件读取、粘贴来源、脚本按文字展示、真实零任务计数、对话与重启保留。文件 chooser 返回值为命名合成 fixture 注入，实际读取由 App main handler 完成，不宣称测过全部 OS 对话选择路径 |

最终打包后检查记录在 evidence/mvp/，安装包摘要在 deliverables/jojo-plan-0.2.0-release-manifest.json。运行测试目录不进入源码或安装包。

## 修复后的行为

材料/补充加入输入指纹；已经交付的旧要求不能沿用新审批。没有新材料/补充的 0.1.0 指纹保持兼容；升级不凭空失效已批准成果。重复审批被拒绝，返工不能跳过前置阶段。审批反馈保存在受信任消息标签中，不错误地当新需求清空全部前序批准。

研发返回 JSON 源码合同，校验相对路径、隐藏/重复文件、外部依赖与大小。构建使用固定 Dockerfile，只 COPY 校验的源码；从 Node 镜像摘要构建后断网、只读、非 root 测试，强制 TAP 输出。导出明确选源码成果，避免把更晚的测试报告误选为源码。

一项工作里可看到实际角色、任务、Job、进程和日志。系统阶段由已批准成果决定；已通过阶段显示进度，不把“前序通过、可以继续”误写成“尚无任何依据”。旧失效历史保留，新的已交付版本推荐交接视图。

## 结论及范围

达到本报告定义的**本机试用 MVP**门槛，可拿来跑自己的文本/Skill工作和小型 Node Web/API 研发闭环。自动搜索发现、OCR/复杂文档、Skill 组、多格式排版、任意技术栈与生产部署仍在后续范围，见 README 与单独待拍板文档。结构检查不证明语义/业务正确，原生品质检查也不构成 Awwwards/Webby/FWA 获奖认证。

全部真实模型输入都是合成，模型使用现有登录本机 Codex 经 Pi Agent Core 调用；没有读出或迁移登录凭据，没有推送 Git、发布网站或使用生产环境。两种 BYO API 已测本机协议，但真实供应商、真实客户材料、目标 macOS 14/Intel/干净机与 Apple 签名/公证尚未验收。
