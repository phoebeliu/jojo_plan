# 0.4.0-alpha.1 本机验收版

2026-11-18。面向本机 Apple Silicon 试用。退出旧版后打开新版，沿用同一份本地项目数据。升级前可通过「模型与设置」的本机备份入口保留快照。

现在可在「查看约定与依据」登记研发验收。记录包含验收项、结果、环境、记录人、实测说明和被测源码版本的 SHA-256。工作区显示当前源码对应的记录，终审读取这些证据，交接清单包含关联字段。若已有终审结论，新增记录使该结论需要重新审阅，已通过的研发及前序阶段继续有效。

运行提示区分执行中、取消、模型调用失败、达到 Codex 时限和进程中断。重启后选用上次运行的模型及已存工作预算，实际发送仍需当前操作授权。交付文档中的常用 Markdown 表格使用可访问的列标题和单元格。新包会从应用版本元数据显示版本号。

实测已从 0.3.1 的原工作继续，使用原始源码在受控内部 Docker 网络中完成正式网页到真实模型的问答。浏览器首次请求返回 HTTP 200，计划组件按输入显示两天各一项，操作后计数由 0/2 变为 1/2。验收记录通过原生界面登记并重启复核，原工作已进入终审。测试使用专用固定中转和本机登录模型，生成程序容器没有直接公网出口。现有默认容器单测仍保持断网。专用验证脚本和证据随本机项目交接保存。

实际终审已生成报告。报告要求独立复核原始附件和逐项记录，项目保留终审待审阅。应用已导出源码、验收记录及终审版本，逐文件通过校验。完整的本机交接包另附逐项证据索引、实测截图和日志。

TypeScript 检查、28 项核心测试和打包版 12 项原生检查均通过。原有 POC 的 11 项断网单测再次通过。本机包的位置和校验和见[安装包清单](../../deliverables/jojo-plan-0.4.0-alpha.1-release-manifest.json)。

范围限本机 Alpha 和受测 POC。当前证据入口保存的是记录正文与关联版本，原始附件由本机交接包承载。应用内原始附件核验、通用模型集成任务调度、其他模型供应商实测、销售穿行团队闭环与生产发布留在后续迭代。登记实测结论仍需独立审阅后才可批准交付。
