# 0.3.0 本机材料与 Python 迭代

2026-10-12。本轮实际开发，按已确认方向将公开材料接入 App。当前仍仅本机使用；没有发布服务或安排外部分发。原 0.2.0 七阶段/Personal AI/Intelligent UI 功能继续保留。

## 已实现

- 原生文件选择支持 PDF、PNG、JPEG；原始字节以内容寻址保存，记录 SHA-256、来源与版本。交接 ZIP 可恢复原文件，备份/恢复包含它们。
- PDF.js 6.4.299 本地文字提取，可选页码（默认1–20页，允许1–500）；保留 PDF 物理页码、页文字摘要与派生关系。文字结果上限200,000字符，截断有记录；扫描页显示需要OCR，不伪造提取文本。文本顺序不等于表格结构识别。
- macOS Apple Vision helper 本地 OCR、人脸区域计数、文字置信度与归一化坐标。原图预览仅在实际解析成功后启用；结果注明未做真伪认证，不做人脸身份比对。
- 新建系统工作可选择 Node 或 Python；合同固定执行栈，源码与批准合同不一致时拒绝测试通过。Python限定标准库、server.py 与 tests/test_*.py，使用 unittest，至少两条未跳过的通过测试；运行容器仍断网、只读、非root、无宿主挂载，基础镜像锁定摘要。
- 解析有真实任务/Job/完成或失败记录，Vision子进程记录真实PID。解析失败仍保留原件，但不创建成功解析依据。模型只获得提取文本与缺口提示，原图不自动上传。
- app.snapshot 不再将大图快照逐次写入幂等缓存，避免每次刷新重复保存图像。没有新材料的既有输入指纹保持兼容。

## 使用与当前边界

[本机安装包](../../release/Jojo%20Plan-0.3.0-arm64-mac.zip)。退出旧App后替换，沿用用户数据目录；目标arm64/macOS14，实际验证平台仍是本机macOS27。运行已打包App不需要Swift工具链；从源码构建需本机Xcode Command Line Tools。

“材料与来源”填写来源、选择PDF起止页，再选文件；解析完成后从成果列表读原件和派生结果，展开来源定位与置信度。原始文件上限8MB，文本200KB，每次最多10个、本次编码合计32MB。多文件按工作项串行解析，不并发混入正在生成的上下文。

尚未实现：扫描PDF整页OCR/Word解析、护照字段/MRZ完整校验与有标签鉴假评测、销售凭证表格/逐笔勾稽执行器、第三方Python依赖或外部能力供应商、自动搜索发现、ontology 8 Skill组。下一轮按已确认路线补这些能力；本轮没有把“识别文字/看见人脸”写成“鉴假完成”，也没有把公开问询回复当成原始130笔凭证。
