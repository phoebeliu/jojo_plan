# 0.3.1 本机实测修正

2026-10-13。本机使用，不对外发行。

## 问题与修正

从已安装 0.3.0 的现有 Intelligent UI 工作推进，研究、PRD、UIUX 可生成并持久保存，但架构角色将“无外部依赖”误解为“不接入模型”，建议用本地规则替代已批准的模型生成并修改验收。该架构已被拒绝，保留返工意见与历史版本。

0.3.1 明确区分第三方包限制、隔离容器测试与交付系统的模型接入：不安装第三方包；容器单测保持禁网，使用明确标注的注入传输；智能生成需求必须保留真实模型接入，不能擅自降级为规则或固定模板。Python 可用标准库 urllib 调用部署方显式配置的模型服务，凭据只在服务端配置，未配置必须明确报错。

## 已验证

- TypeScript 类型检查通过。
- 27 项核心与协议测试通过（协议夹具需要回环监听权限，测试使用隔离数据）。
- 0.3.1 打包版的 4 项材料回归通过：Python 工作约定、PDF 选页与来源、原生 OCR 和图片预览、重启保留材料。
- 原有用户工作在 0.3.1 重启后恢复，保留前序三个阶段、被拒绝的架构及审阅意见。

以上检查不证明全部生成系统的语义正确性；实际项目仍需真实研发测试、界面与模型链路验收。

## 本轮发现的其他问题

- 本机 Codex WebSocket 连接重置后会回退 HTTPS；错误事件不能直接等同于最终失败。
- 单次 PRD 请求曾达到 240 秒超时，后续明确配置本机模型并重试成功。失败用量按预留上限保守核对，未伪造准确用量。
- 运行中顶部仍显示旧的“可以开始”提示，失败原因未清楚展示。
- 对话区 Markdown 表格未按表格渲染。
- 模型配置显示相同名称时不易区分；重启后选定模型需再次确认。

后几项尚未在 0.3.1 修复，作为后续内测问题保留。0.3.1 仍为未签名、未公证的 Apple Silicon 本机 Alpha，不能声明普遍可安装、获奖品质或全业务验收通过。
