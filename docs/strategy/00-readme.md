# jojo plan：为什么值得存在

战略修订 S2｜2026-10-09（保留S1研究）｜建议方案，待真实用户验证。产品仍是文档与交互设计，未有可安装应用、付费客户或对照实验成绩。

**当前建议定位：AI 项目负责人的个人交付替身。按你认可的方法组织任务，以可追溯的依据验收，并提供适合当前问题的交互。**

优先阅读[Personal AI与Intelligent UI研究/定位](07-personal-ai-intelligent-ui.md)。S1交付闭环继续作为底座，S2增加个人方法、可解释情境组件与控制；不声称已经形成不可替代性。

目标不是让用户换掉所有 AI 工具，而是让已有工具产出的研究、设计、代码与测试形成可维护的交付记录。模型执行是必要底座；减少负责人亲自串联、查漏和追溯的时间，才是待证明的购买理由。

当前不能诚实地说 jojo 已比 Hermes、DeepSeek Harness、Codex 或 Claude Code 更值得使用。对话、桌面、技能、多代理、流程模板和结果验证都有强替代品；没有一种单项能力已建立排他优势。我们应争取在一个明确任务上成为首选，而非宣称对所有用户不可替代。
