# S2：面向交付负责人的 Personal AI 与 Intelligent UI

2026-10-09｜产品设计建议，尚未真实用户验证。S2在S1可验收交付之上增加个人方法与情境界面，不改变已确认的单人、本地、三类工作和Pi首适配器。

**定位：jojo plan 是 AI 项目负责人的个人交付替身。它按你认可的工作方法组织任务，用可追溯的依据验收结果，并把适合当前问题的交互带到面前。**

## 1. 最新实践与我们采用的含义

这些概念没有单一统一的行业规格。此处personal AI泛指个人化的AI系统，不指某个同名品牌；intelligent UI包括上下文适配、主动建议与可解释交互，generative UI只是其中一种实现方式。

## 2. 将个人化分成四种知识

1. **个人工作准则**：你明确说过的流程、表达与审阅偏好。例：系统先研究/PRD、UIUX、宣讲、工程设计，再研发测试、综合验收。
2. **项目约束**：审计项目、护照项目的范围、材料权限和规则，仅在各自项目使用。领域规则不能变成全局习惯。
3. **经验证的方法**：一次失败如何修复、在哪些条件下有效、用哪些样例验证。只有审阅和回归检查完成的方法版本可以启用。
4. **当前工作状态**：哪条依据失效、哪个任务失败、哪些内容未完成。它来自运行与版本记录，不通过长期记忆覆盖。

个人AI的作用是减少重复解释、提前发现惯常遗漏，并提出可审阅的方法改进。它不假装具有个人意识，也不凭偏好接受缺陷或宣布验收通过。

## 3. Intelligent UI的产品形式

稳定的对话与导航是骨架，按情境变化的检查点是工作面：研究时整理来源与未知；系统设计时核对约定和依赖；需求改变时对照版本与受影响项；报告写作时核查声明及原始记录；交接时展示未完成项与复现方式。

推荐卡说明「为什么显示、用了哪些个人准则和项目状态、还有什么不确定」。用户可以固定当前检查点、恢复自动推荐，或暂时不使用个人准则。固定只影响展示，不阻止新风险提示，也不冻结实际交付状态。

首版选择受控组件：evidence-review、scope-clarification、method-validation、source-review、change-review、handoff-checklist。AI可建议组件与数据；服务检查适用范围、对象版本与权限，再由客户端渲染。不执行模型任意生成的脚本，也不让模型修改审批按钮的含义。不是每次重新生成整个应用。

## 5. 护城河的设计，而非已有护城河声明

可防守的核心假设是：**经用户接受的个人方法 + 失败/修复/验收结果 + 持续交付关系**能改善下一次工作的选择、核查和返工。单项记忆、聊天、可换模型或生成界面均容易替代。

| 积累机制 | 所需证据 | 为什么用户愿意继续用 | 最强反击 |
| --- | --- | --- | --- |
| 个人方法闭环 | 方法修改前后、适用范围、留出样例结果 | 减少重复说明与相同错误 | 大厂增加等效功能；个人资产可迁移 |
| 工作结果与建议关联 | 哪种建议在何种任务被接受/拒绝、实际检查结果 | 推荐越来越贴近实际工作，减少无关提醒 | 小样本或偏好反馈不能证明任务质量提升 |
| 项目连续性 | 同一要求跨版本的依据、影响与复验历史 | 交接和变化时容易继续 | 模型或方法工具也能实现关系维护 |
| 经许可的公共方法与评测 | 自建/授权样例、版本回归、独立盲评 | 在特定交付任务中稳定可靠 | 当前没有独家语料、分发网络或长期成绩 |

用户自己的方法资产具有个人价值，但不是公司独占资产。可完整导出；默认不上传客户材料，也不自动汇聚跨用户经验。公司的优势应来自方法维护、验证器与体验效率，不能以扣留数据制造不可替代性。

## 6. 实测：个人化和智能界面分别值得什么

在原S1对照基础上增加消融：A成熟Agent+成熟方法，B仅jojo交付闭环，C增加个人准则，D再加情境推荐。相同任务、模型/工具预算与合成变更，随机交叉顺序。

测人工分钟、重复解释次数、必要审阅遗漏、错误个性化次数、推荐纠正成本、完成质量及工具成本。建议继续门槛：相对B，C+D人工分钟中位数再降低≥15%，质量不下降；项目间规则串用及偏好绕过审批为0；至少80%的推荐能由用户正确解释其依据。阈值是设计假设，不是已有结果。

连续两个工作周期后，若收益不足或纠正成本过高，保留可控工作准则，关闭主动推荐；若现有工具加轻量方法达到相同收益，按S1形态选择原则转插件。只在证据支持的场景内宣传，不能说对所有人永久不可替代。

## 7. 给用户和投资人的表达

用户：**Jojo记住你认可的做事方法，把当前最需要核查的部分带到面前，让每次交付有依据。** 当前为设计演示，尚无真实长期学习。

投资人：从个人工作方法的累积与结果反馈建立留存，通过有来源、有版本、可回归的方法提升交付效率。模型提供执行能力，jojo争取拥有方法维护与交付体验的优势。尚未证明数据壁垒、PMF或竞争收益。

市场演示：先展示「按你的五阶段流程」及其来源，再切到护照项目证明业务规则隔离；应用销售穿行的合成变更，检查点转成重验；展示推荐原因、固定显示、关闭个人准则，以及待确认的经验候选。不能用演示截图宣传真实Agent已自主学习。
